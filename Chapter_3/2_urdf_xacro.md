# [과제 3-2] 간단한 로봇 모델 생성 및 URDF/xacro 조사 보고서

## 1. URDF, 링크, 조인트의 개념 조사

### 1.1. URDF (Unified Robot Description Format)
URDF는 ROS에서 로봇의 물리적 구조(외형, 관성, 충돌 영역 등)를 정의할 때 사용하는 표준 **XML 기반의 파일 형식**입니다. 로봇이 시뮬레이션 환경이나 실제 환경에서 어떻게 생겼고, 관절들이 어떻게 움직이는지 정의하는 명세서 역할을 합니다.

### 1.2. 링크(Link)와 조인트(Joint)
* **링크 (Link):** 로봇을 구성하는 각각의 '단단한 부품(강체)'을 의미합니다. (예: 로봇의 몸통, 바퀴, 팔 등). 링크 태그 내부에는 눈에 보이는 형태(`visual`), 물리적 충돌 영역(`collision`), 질량 및 관성(`inertial`) 정보가 포함됩니다.
* **조인트 (Joint):** 두 개의 링크를 연결하는 '관절'을 의미합니다. 조인트는 부모 링크(Parent)와 자식 링크(Child) 간의 상대적인 위치(`origin`)와 회전/이동 방식(`type`, `axis`)을 정의합니다. 이번 실습의 바퀴처럼 무한히 회전해야 하는 경우 `continuous` 타입을 사용합니다.

---

## 2. xacro 파일의 용도 및 구조

### 2.1. xacro 란?
xacro(XML Macros)는 복잡하고 길어지기 쉬운 URDF XML 파일을 더 짧고 읽기 쉽게 작성할 수 있도록 도와주는 **매크로 언어**입니다. 변수를 선언하거나, 반복되는 코드를 매크로 함수처럼 만들어 재사용할 수 있게 해줍니다.

### 2.2. URDF와 xacro의 차이점 및 장점 (유지보수 관점)
* **차이점:** URDF는 로봇의 좌/우 바퀴처럼 똑같이 생긴 부품도 코드를 처음부터 끝까지 중복해서 작성해야 합니다. 반면, xacro는 프로그래밍 언어의 함수처럼 템플릿(매크로)을 만들어 변수값만 다르게 전달하여 생성할 수 있습니다.
* **장점 (간소화 및 유지보수성):** 코드의 중복을 획기적으로 줄일 수 있습니다. 만약 바퀴의 크기를 변경해야 한다면, URDF는 모든 바퀴 코드를 일일이 찾아 수정해야 하지만, xacro는 매크로 정의부 한 곳만 수정하면 전체 모델에 일괄 적용되므로 유지보수에 매우 유리합니다.

### 2.3. xacro를 활용한 바퀴 구조 재사용 방법
xacro 파일에서는 `<xacro:macro>` 태그를 사용해 공통 속성을 묶습니다.
이번 실습에서는 `wheel`이라는 이름의 매크로를 정의하고, `name`과 `xyz`(좌표)를 매개변수(params)로 받게 설정했습니다. 
이를 통해 몸체 구조를 정의한 후, 아래와 같이 단 두 줄의 코드로 왼쪽 바퀴와 오른쪽 바퀴를 생성하여 중복 구성을 방지했습니다.
* `<xacro:wheel name="left_wheel" xyz="0 -0.15 0.05"/>`
* `<xacro:wheel name="right_wheel" xyz="0 0.15 0.05"/>`

## 3. 작성한 로봇 모델의 규격 상세 설명

제작한 `simple_robot.urdf` 및 `simple_robot.xacro` 모델은 다음과 같은 규격과 연결 구조를 가집니다.

* **몸통 (base_link):** 
  * 형태: 박스형 (Box)
  * 크기: 가로(x) 0.5m, 세로(y) 0.3m, 높이(z) 0.2m
  * 색상: 파란색 (`rgba="0 0 1 1"`)
  * 질량: 1.0 kg
* **바퀴 (left_wheel, right_wheel):**
  * 형태: 원통형 (Cylinder)
  * 크기: 반지름 0.05m (5cm), 두께 0.02m (2cm)
  * 색상: 검은색 (`rgba="0 0 0 1"`)
  * 질량: 각각 0.1 kg
* **연결 구조 (Joints):**
  * 베이스 중심(0, 0, 0)을 기준으로, 왼쪽 바퀴는 y축 방향으로 -0.15m, 오른쪽 바퀴는 +0.15m 떨어져 배치되었습니다. (z축으로는 +0.05m 띄워 연결)
  * 바퀴가 지면과 닿아 정상적으로 굴러갈 수 있도록 `rpy="1.5708 0 0"` (x축 기준 90도 회전) 옵션을 주어 눕혔으며, z축(`axis xyz="0 0 1"`)을 기준으로 회전하는 `continuous` 조인트로 연결되었습니다.

## 4. RViz2 모델 확인 및 동작 테스트 결과

* **실행 명령어:**
  * URDF 확인: `ros2 launch urdf_tutorial display.launch.py model:=simple_robot.urdf`
  * xacro 확인: `ros2 launch urdf_tutorial display.launch.py model:=simple_robot.xacro`
* **동작 확인 결과:** 위 명령어를 통해 RViz2를 실행한 결과, 정의한 규격대로 파란색 몸통에 검은색 바퀴 2개가 올바른 위치에 부착된 것을 확인하였습니다. 
* 함께 실행된 `Joint State Publisher` UI의 슬라이더를 조작했을 때, 지정한 `continuous` 조인트의 z축(바퀴 축)을 중심으로 두 바퀴가 정상적인 방향으로 회전하는 것을 테스트 완료하였습니다.
