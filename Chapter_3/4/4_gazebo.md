# [과제 3-4] Gazebo 시뮬레이터 실습 및 물리 시뮬레이션 보고서

## 1. Gazebo 시뮬레이터 개요 및 RViz2와의 차이점

### 1.1. Gazebo 시뮬레이터란?

Gazebo는 로봇 공학에서 널리 사용되는 **3D 동역학(Physics) 시뮬레이터**입니다. 로봇 모델뿐만 아니라 조명, 중력, 마찰력, 장애물 등 실제 현실과 유사한 물리적 환경을 제공하여, 실제 하드웨어 없이도 로봇의 주행 및 제어 알고리즘을 테스트할 수 있게 해줍니다.

### 1.2. Gazebo와 RViz2의 가장 큰 차이점 두 가지 (평가 대비)

| 구분                    | Gazebo (시뮬레이터)                                                                            | RViz2 (시각화 도구)                                                                                                   |
| :---------------------- | :--------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------- |
| **물리 엔진 적용 여부** | **적용됨 (O)**. 중력, 마찰력, 충돌, 탄성 등 실제 물리법칙이 적용되어 물체가 떨어지거나 부딪힘. | **적용 안 됨 (X)**. 물리 법칙 없이 센서나 노드에서 전달받은 데이터(TF)가 가리키는 위치에 물체를 단순히 '그려줄' 뿐임. |
| **사용 목적**           | 가상 환경 속에서 로봇이 **'실제로 어떻게 동작하고 상호작용하는지'** 테스트(동역학 검증).       | 로봇이 **'현재 어떤 데이터를 보고 있고, 자신을 어디에 있다고 생각하는지'** 눈으로 확인(데이터 시각화).                |

## 2. Gazebo 시뮬레이터 설치 및 물리 시뮬레이션 테스트 기록

**설치 명령어:** `sudo apt install ros-humble-gazebo*`

### 2.1. 3차원 축(Axis) 색상 확인 및 RViz2 비교

- **테스트 내용:** Gazebo 상단 메뉴에서 Box를 생성하고 이동(Translate) 아이콘을 클릭하여 축을 확인.
- **확인 결과:** Gazebo의 축 색상은 **빨간색(X축), 초록색(Y축), 파란색(Z축)** 으로 나타났으며, 이는 **RViz2의 TF 축 색상 배열과 완전히 동일**함을 확인했습니다. (RGB = XYZ 규칙)

### 2.2. 중력 및 자유 낙하 테스트 (Play 상태)

- **테스트 내용:** 파란색(Z축) 화살표를 드래그하여 박스를 공중으로 띄움.
- **확인 결과:** 마우스 클릭을 놓는 순간, Gazebo 물리 엔진의 중력(Gravity) 설정에 의해 박스가 바닥으로 자유 낙하하여 부딪히는 것을 확인했습니다.

### 2.3. 시뮬레이션 제어 (Pause / Play) 테스트

- **테스트 내용:** 하단의 일시정지(Pause) 버튼을 누른 후 박스를 공중으로 올리고 다시 재생(Play) 버튼 클릭.
- **확인 결과:** Pause 상태에서는 시간을 멈춘 것처럼 박스가 공중에 고정되어 떨어지지 않았고, 이동시킨 위치 그대로 유지되었습니다. 이후 Play로 전환하자마자 누적된 물리 법칙(중력)이 즉시 작용하여 바닥으로 떨어졌습니다.

### 2.4. 복합 물리 충돌 테스트 (구와 박스)

- **테스트 내용:** Pause 상태에서 박스를 바닥에 두고, 그 위 모서리 부근에 구(Sphere)를 공중에 배치한 후 Play 클릭.
- **확인 결과:** 구가 자유 낙하하여 박스의 모서리에 충돌한 뒤, 충돌 각도와 중력의 영향으로 바닥으로 굴러 떨어지는 자연스러운 물리적 상호작용이 연출되었습니다.

## 3. 탄성(Bouncing) 모델의 특성 및 적용 방법 (평가 대비)

Gazebo의 Insert 탭을 통해 다양한 물체를 추가해 본 결과, 기본 구형 모델과 달리 바닥에 충돌했을 때 통통 튀어 오르는 모델(예: 고무공 모델 등)을 확인했습니다.

### 3.1. 탄성이 있는 모델의 물리적 특성

일반적인 모델과 달리 탄성 모델은 물리 충돌 시 에너지를 흡수하지 않고 반사하는 특성을 가집니다.

- **복원력 (Restitution / Bounciness):** 물체가 충돌했을 때 충격 이전의 속도 대비 튕겨 나가는 속도의 비율(반발 계수)을 의미합니다. 이 값이 높을수록 물체가 크게 튀어 오릅니다.
- **댐핑 효과 (Damping):** 스프링이나 관절에서 움직임을 억제하여 에너지를 서서히 잃게 만드는 저항력입니다. 댐핑 값이 있으면 물체가 튀어 오르다가 점차 진폭이 줄어들며 멈추게 됩니다.
- **탄성 제한:** 너무 작은 충격에서는 튕기지 않도록 하는 임계값(Threshold) 속도를 설정할 수 있습니다.

### 3.2. 특성 값을 모델 파일에 적용하는 방법

이러한 물리적 특성 값은 로봇의 외형을 정의하는 **SDF(Simulation Description Format) 또는 URDF 파일 내에 태그 형태로 명시**하여 시뮬레이터 엔진(Gazebo)에 전달합니다.

- **SDF 적용 예시:** `<collision>` 태그 하위의 `<surface>` ➔ `<bounce>` 태그 내에 반발 계수(`restitution_coefficient`)와 임계값(`threshold`)을 입력하여 설정합니다.
  ```xml
  <surface>
    <bounce>
      <restitution_coefficient>0.8</restitution_coefficient>
      <threshold>0.01</threshold>
    </bounce>
  </surface>
  ```
